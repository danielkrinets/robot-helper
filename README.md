# Робот-помощник

Программа для человека, который плохо знает компьютер. Он пишет или диктует просьбу («открой почту и напиши внуку»), а робот-помощник сам делает это мышью и клавиатурой. Всё время видно, что робот работает: по краям экрана оранжевая рамка, рядом с курсором оранжевый значок, сверху подпись «Сейчас…». Остановить робота можно в любой момент большой красной кнопкой **СТОП** или клавишей **Esc**.

Внутри работает Claude API (computer use). Ключа API в коде нет, его вводят вручную при первом запуске.

## Важно знать заранее

- **Скриншоты экрана отправляются в Claude API (Anthropic).** Скажите об этом человеку, которому ставите программу.
- **Защита держится на инструкциях для робота.** Робот не вводит пароли и данные карт и спрашивает «Да/Нет» перед отправкой, оплатой и удалением. Но текст-ловушка на странице или в письме может обмануть робота. Не оставляйте его работать без присмотра в банке и на сайтах с оплатой.
- **Расходы идут с вашего аккаунта.** Каждая задача стоит денег: несколько скриншотов на модели Claude Haiku 5.5 (уровень усилий medium, самая дешёвая из подходящих). Поставьте лимит расходов в консоли Anthropic (Settings → Limits).

## Установка

### Готовая сборка

Сборки делаются автоматически в GitHub Actions: вкладка **Actions** → последний запуск **build** → артефакты `RobotHelper-windows-latest` (`.exe`) и `RobotHelper-macos-latest` (`.app`).

### Из исходников

```bash
python3 -m venv .venv
.venv/bin/pip install anthropic pyautogui pynput pillow keyring pyperclip
.venv/bin/python -m robot_helper
```

На Windows: `.venv\Scripts\python -m robot_helper`.

## Первый запуск (делаете вы, а не пользователь)

1. Откроется экран настройки. Вставьте ключ Claude API (создаётся в консоли Anthropic) и нажмите «Сохранить». Ключ сохраняется в системном хранилище паролей (Windows Credential Manager / macOS Keychain), в файлы не пишется. Вместо этого можно задать переменную окружения `ANTHROPIC_API_KEY`.
2. **Только macOS:** откройте «Системные настройки → Конфиденциальность и безопасность» и разрешите программе **Универсальный доступ**, **Запись экрана** и **Мониторинг ввода** (без него не работает клавиша Esc). Затем нажмите «Проверить снова».
3. **Только Windows:** для озвучки нужен русский голос. Если его нет, установите его в «Параметры → Время и язык → Речь»; без голоса робот просто показывает текст.

## Как пользоваться

- Напишите просьбу в большое поле и нажмите **Отправить** (или Enter).
- Кнопка с микрофоном включает системную диктовку. На Windows она откроется сама (Win+H). На Mac нажмите два раза клавишу Fn (глобус).
- Пока робот работает, главное окно скрыто. Если вы возьмёте мышку, робот спросит, продолжать ли.
- Когда нужен пароль или код из СМС, робот попросит ввести его самому и подождёт кнопку **Готово**.

## Что проверено, а что нет

- Ядро (цикл робота, остановка, подтверждения, ошибки, пересчёт координат) покрыто тестами: `pytest`.
- На macOS проверено, что программа запускается. **Задачу с настоящим ключом не прогоняли**, рамку и значок глазами не смотрели.
- **На Windows программа не проверялась вообще.** Проверьте её на реальном компьютере и пришлите ошибки.
- Распознавания речи внутри программы нет: используется системная диктовка.

## Разработка

```bash
.venv/bin/pip install pytest
.venv/bin/pytest
```
